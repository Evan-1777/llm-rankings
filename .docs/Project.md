# Project

> 项目的单一事实来源，供 Agent 动手前建立全局认知。定位与设计原则见 `SCOPE.md`，工作流规则见 `AGENTS.md`。

## 概述

- **定位**：LLM Rank，一个用于个人记录、评分与比较 LLM 表现的自托管 Web 服务。
- **阶段**：首版实现完成（2026-10-22）。代码、测试、部署配置与 CI 已落地；生产镜像由 GitHub Actions 构建。
- **当前增量**：模型评语与审阅残留收口：模型档案新增独立评语、公开开关与手填评语日期，详情页底部展示评语并内联日期，未公开评语仅管理员可见；设置页模型弹窗录入三项；隐藏模型退出匿名模型列表且匿名详情返回 404；工作台隐藏行覆盖率弱化；新建维度默认权重 50；隐藏模型详情的强度基准合并自身（2026-10-23）。
- **上一增量**：模型生命周期与文字维度：模型新增「隐藏 / 显示」与「归档 / 恢复 / 永久删除」，隐藏模型只留在评分工作台与详情直链；维度权重 0 统一为「不纳入评分」，数值仍展示但不进入综合分、覆盖率与名次；维度新增「填入文字」，按模型保存一段中英文自由文本，只在详情页展示、评分弹窗录入；维护页撤下登录入口并前移门禁认证判定（2026-10-22）。
- **首版范围**：单管理员维护模型、维度、全局维度权重与评分；公开只读排行；加权综合分与覆盖率；模型详情、对比、评分工作台；JSON 导出；Docker Compose 与 GHCR 镜像。
- **非目标**：多用户/注册/OAuth、评论社区、自动抓取 benchmark、AI 自动评分、原生 App、实时协作、国际化、付费、暗色主题、评分历史、JSON 导入。

## 环境与运行

- **平台**：Linux x86_64（WSL 文件系统），开发与测试在本机；生产为个人 VPS。
- **Shell**：bash
- **运行时**：Go 1.27；Node 24 + pnpm 11.23；SQLite（modernc.org/sqlite，纯 Go，无 CGO）；React 19 + TypeScript 7 + Vite 8。
- **版本管理**：git；远端 [Evan-1777/llm-rankings](https://github.com/Evan-1777/llm-rankings)（公开）；`master` 为当前分支。
- **依赖**：Go 模块（`go.mod` / `go.sum`）；前端 pnpm（`web/pnpm-lock.yaml`）。生产镜像由 CI 构建，本机无 Docker。
- **本地运行**：
  1. `pnpm --dir web install`
  2. `pnpm --dir web build`（写入 `web/dist`，供 Go 内嵌）
  3. 设置必需环境变量后运行 `go run ./cmd/server`
  4. 开发前端时可运行 `pnpm --dir web dev`，Vite 将 `/api` 代理到 `127.0.0.1:8080`
- **环境变量**：
  - `PORT`：监听端口，默认 8080。
  - `DB_PATH`：SQLite 文件路径，默认 `./llm-rank.db`；生产为 `/data/llm-rank.db`。
  - `ADMIN_PASSWORD_HASH`：必填，bcrypt 哈希；缺失或格式错误时启动失败。
  - `SESSION_SECRET`：必填，至少 32 字节；用于 HMAC 签名 Cookie。
  - `COOKIE_SECURE`：默认 false；HTTPS 生产环境设为 true。
  - `TRUST_PROXY`：默认 false；仅当反向代理覆盖 `X-Forwarded-For` 时设为 true。
- **测试**：
  - `go test ./...`
  - `go vet ./...`
  - `pnpm --dir web typecheck`
  - `pnpm --dir web test`（Node 原生 `node --test`）
  - `pnpm --dir web build`
  - `CGO_ENABLED=0 go build ./cmd/server`
- **部署**：
  - CI 将镜像推送到 `ghcr.io/evan-1777/llm-rankings`（`latest` 与 `sha-*`、分支、版本标签）。
  - 复制 `deploy/.env.example` 为 `deploy/.env`，填写镜像、密码哈希与会话密钥。
  - `docker compose --env-file deploy/.env -f deploy/compose.yaml pull`
  - `docker compose --env-file deploy/.env -f deploy/compose.yaml up -d`
  - 容器只绑定 `127.0.0.1:8080`，由宿主反向代理终止 TLS；SQLite 使用命名卷 `llm-rank-data` 挂载到 `/data`。
- ★ 本机未安装 Docker；不本地构建镜像，镜像构建由 GitHub Actions 验证。
- ★ 前端构建产物通过 `//go:embed all:dist` 进入 Go 二进制；生产只运行一个进程。
- ★ SQLite 使用 WAL、外键与单连接；备份以卷或 JSON 导出为准。

- **分层**：`api → domain`、`api → store`；`domain` 不依赖 `store` 或 `api`；`store` 不依赖 `api`。评分与排名在 `domain` 计算，HTTP 层只解析与序列化。
- **数据流**：浏览器 → `/api` → `api` → `domain` / `store` → SQLite；响应原路返回。非 API 路径由 Go 内嵌的 SPA 接管。
- **API 面**：
  - `GET /api/health`
  - `GET /api/bootstrap`
  - `POST /api/auth/login`、`POST /api/auth/logout`
  - `GET /api/rankings`；`GET /api/rankings?includeHidden=1`（管理员，隐藏行保留分值与 `hidden: true`，名次为空）
  - `GET /api/display-settings`（公共）；`PUT /api/display-settings`（管理员，需同时提交两个开关）
  - `GET /api/dimensions`；`POST /api/dimensions`；`PATCH /api/dimensions/{id}`；`PUT /api/dimensions/order`；`POST /api/dimensions/{id}/archive|restore`；`DELETE /api/dimensions/{id}`（维度载荷含 `textMode`）
  - `GET /api/models`（匿名不含隐藏模型；管理员列表含 `commentary`、`commentaryPublic`、`commentaryAt`）；`GET /api/models?includeArchived=1`（管理员）；`POST /api/models`（创建不接收评语）；`GET /api/models/{slug}`（公开评语对所有人，未公开评语仅管理员；匿名访问隐藏模型返回 404）；`PATCH /api/models/{slug}`（可只提交 `hidden` 或评语三字段）；`DELETE /api/models/{slug}`
  - `POST /api/models/{slug}/archive|restore`
  - `PUT /api/models/{slug}/scores/{dimensionId}`；`DELETE /api/models/{slug}/scores/{dimensionId}`（文字维度拒绝数值写入）
  - `PUT /api/models/{slug}/texts/{dimensionId}`（管理员，载荷 `{text}`；空串清空并返回 204）
  - `GET /api/export`（管理员，含归档与隐藏模型、维度 `textMode` 与 `texts` 数组、模型评语三字段）
- **数据模型**：`dimensions`（名称、描述、0–100 权重、`text_mode` 0/1、展示位置 `position`、归档时间）、`models`（唯一 slug、名称、厂商、私人备注、`hidden` 0/1、`archived_at`、`commentary`、`commentary_public` 0/1、`commentary_at`）、`scores`（模型 + 维度复合主键、非负 REAL、备注、更新时间）、`dimension_texts`（模型 + 文字维度复合主键、内容、更新时间）、`display_settings`（单例 `id = 1`、`score_percentage_mode` 0/1、`maintenance_mode` 0/1）。表间外键级联；不插入种子数据；展示位置按原 ID 初始化，新建追加末尾。
- **排名规则**：只计权重 > 0 的启用数值维度；权重 0 维度仍出现在排行、详情与对比的展示快照中，但不进入综合分、覆盖率与排序。综合分按已评分维度的权重归一，不设上限，按两位小数展示；单维度评分保留一位小数；覆盖率 = 已评分权重 / 总权重，显示向下截断到一位小数，低于 80% 标记「暂定」；同分按覆盖率高者、名称（小写码点序）、slug 排序；未评分与隐藏模型始终置底，隐藏模型不占名次，可见模型名次连续；官方排名不随视图排序改变。公开排行、对比候选与 bootstrap 计数排除隐藏模型；管理员 `includeHidden=1` 可读取隐藏行。
- **维度排名**：详情页逐维度计算，只计该维度已评分模型；按分值降序、名称与 slug 次序编号，与官方排名共用比较契约；未评分显示破折号，不改变官方综合排名。
- **认证与安全**：bcrypt 哈希存环境变量；HMAC 签名 `llmrank_session` HttpOnly Cookie，24 小时；登录失败每 IP 15 分钟 5 次；写请求校验 Origin host 与 Host 一致；安全响应头含 CSP、`X-Frame-Options`、`X-Content-Type-Options`、`Referrer-Policy`；公开接口不返回私人备注。维护模式开启时，除健康检查、登录、登出与公开显示设置外，匿名 `/api` 请求统一返回 503 `maintenance`；管理员 Cookie 不受影响。门禁先判断登录态，再读取站点设置，已认证请求不触发 `display_settings` 查询。隐藏模型不进入匿名模型列表，匿名详情直链返回 404；管理员模型列表、详情、工作台与设置不受影响。
- **静态资源**：`assets/` 下带哈希文件使用一年 immutable 缓存；其他文件一天；缺失的 `assets/` 与带扩展名路径返回 404，其余路径回落到 `index.html`；API 未知路径返回 JSON 404。

## 前端

- **路由**：`/`（排行）、`/models/:slug`（详情）、`/compare?models=...`（对比）、`/workbench`（工作台）、`/settings?tab=dimensions|models|data|display`（设置）、`/login`（登录）。
- **登录入口**：页头、排行空态与维护页均不渲染登录链接或按钮，`/login` 仅通过直接 URL 访问；未登录访问受保护页由 `RequireAdmin` 重定向到 `/login?next=...`。维护模式开启时，未登录访客访问任意非登录路径只渲染维护页。
- **信息架构**：排行表头即排序控件；评分通过共享评分弹窗或工作台快捷编辑；模型只通过共享模型表单创建；设置页独立于排行，模型分区拆分启用与归档、提供隐藏开关并常驻底部归档区；工作台为语义表格，维度分值常驻并可按表头排序，默认覆盖率升序暴露补测优先级，隐藏模型浅灰置于可见行之后；详情页同时展示综合排名与逐维度名次，文字维度在数值表下方独立阅读，其后依次为模型评语与管理员私人备注；设置页模型行只按可评分维度展示完整度（接口另返回全部评分总数）；对比最多 4 个模型，移动端改为纵向卡片。
- **厂商候选**：模型表单接收父页已加载的完整模型列表，按厂商 trim、去空、精确去重后以中文 locale 排序；原生 select 提供“不填写”、已有厂商与“新厂商…”，选择只更新当前字段，不提交表单；候选来自父页快照，不额外请求。
- **显示偏好**：管理员设置“显示”分区并列三个开关。“百分比模式”为站点级设置，存 `display_settings`，默认关闭，排行、详情、对比三处只读评分表面与移动对比卡片共享，开启后综合分与维度分改为相对强度百分比（100% 最强、1% 最弱），所有访客生效，详情相对条按同一强度值填充（越强越长）；“维度得分强调”默认开启，仍只存当前浏览器 localStorage，共享红蓝色阶。“维护模式”为站点级开关，默认关闭，开启后未登录访客只显示维护页；两个站点开关一次提交完整值，保存失败同时回滚。评分工作台与评分弹窗始终显示实际分值，不随两种模式改变。
- **状态**：每页具备加载骨架、错误重试、空状态与成功反馈；维护页不渲染页头与导航；站点设置尚未返回时先显示加载占位，避免维护页闪烁；无数据时给出下一步入口（先建维度 / 新增模型 / 去评分）；空态只依据本页已加载数据，bootstrap 计数仅作加载前占位。
- **交互与可访问性基准**：沿用首版方案的 Apple HIG，包含清晰层级、克制反馈、键盘操作与焦点恢复；设置页 Tab 使用 roving tabindex 与左右方向键，维度手柄在读屏名称与 `aria-keyshortcuts` 中说明上下方向键；视觉执行瑞士平面规范。
- **视觉**：瑞士/编辑式排版，纸白 `#F2EFE6`、墨黑 `#14130F`、信号红 `#B92A20`；0 圆角、无阴影/渐变、1px 分隔线；桌面 12 栏，内容最大 1500px；移动端表格隐藏维度列（排行、详情与对比；工作台仅表格容器横向滚动），保留排名、模型、综合分、覆盖率与操作；隐藏模型在工作台的模型名、厂商、维度值、综合分、名次、覆盖率数字与进度条统一使用 `--ink-3`（约 4.97:1），覆盖率「暂定」标记保留信号红，不新增更浅令牌；功能文字不小于 10px，移动主按钮 44px，行内图标 34px；维度拖动手柄桌面 52×44px、≤900px 44×48px，对应首列 60/44px；详情维度表新增右对齐的等宽数字名次列，移动端保留名次并隐藏相对条。
- **维度色阶**：只读维度得分按全榜同维度有限非负值 min/max 定位，低分端暖红 `#e89a8b`（下划线 `#8f1c14`），高分端冷蓝 `#9fcbd2`（下划线 `#174f5b`），中点回到纸白；强度取 `0.18 + 0.82 × 距中点比例`，以百分比写入 `color-mix()`，端点满强度。文字保持墨黑，端点对比度 8.34:1（红）与 10.57:1（蓝）；2px 下划线跟随分值文字宽度（不跨越色块内边距），给出不依赖底色的方向。排行与详情在强调开启时显示“低分红 → 高分蓝”图例；`forced-colors` 与打印移除底色与下划线。色阶只依据实际得分，不依据百分比数字，也不参与综合分、覆盖率或排名。
- **交互细节**：评分弹窗打开后优先聚焦首个数值输入，无数值维度时聚焦首个文本框；未保存改动拦截站内跳转与 `beforeunload`；关闭后焦点回到触发按钮；评分预览实时更新综合分与排名，预览前按 slug 合并当前模型、不依赖公开排行是否包含它；隐藏模型预览置底且不编号；评分输入拒绝负数、NaN、Infinity，允许 12.5 与更大有限值；文字维度使用多行输入（上限 2000 字符），与数值评分串行保存，空文字清空记录；备注只能附属于已评分维度，评分留空时入口禁用并隐藏编辑区；保存失败保留弹窗与草稿，页脚显示原因，部分写入时说明已提交数量，评分删除可重复调用以便重试。
- **模型生命周期**：设置页模型分区按名称列出启用模型，行内依次提供查看、编辑、隐藏/显示、归档与永久删除；隐藏模型显示「已隐藏」标签，仍保留在设置列表以便恢复显示；归档模型只出现在列表下方的「已归档」区，可恢复或永久删除，删除确认说明级联评分与文字。编辑弹窗仅编辑态提供模型评语、评语时间与公开开关，私人备注保持最后；创建弹窗不出现评语字段。
- **工作台快捷编辑**：工具栏开关文案固定为“快捷编辑”，以 `aria-pressed` 表示状态；编辑态把维度单元格换成同尺寸无边框输入，不新增行、不重复标签、不改变行高；综合分、名次、覆盖率与行顺序冻结，显式表头排序只重排视图并按 slug 保留草稿，保存中仍可用；保存按模型 slug + 维度 id 串行提交，空值删除、未变化不请求、省略备注保留原备注；每成功一项推进基线，部分失败显示已保存/剩余数量，取消只放弃剩余未提交项；保存成功后重载并按当前排序重排；保存中禁用输入、底部操作与模式开关，保存态离开确认说明已发出请求会完成、剩余项不再提交，组件卸载后不再提示或回写；未保存时拦截站内跳转、刷新与退出，退出或保存后焦点回到开关。
- **显示交互**：两个显示开关点击与 Space 均可切换；百分比切换先乐观更新再写站点设置，失败回滚并提示，读取失败回退实际分值；维度强调仍写当前浏览器 localStorage，键为 `llmrank:dimension-score-emphasis`，只认 `true`/`false`，写入失败提示“显示设置仅在本次会话生效”。旧百分比本地键不再读取；站点百分比由管理员切换后，其他设备刷新读取，不做实时推送。
- **维度排序**：设置页维度列表的序号区为拖动手柄；拖动或方向键调整顺序，释放后一次性提交含归档项的完整 ID 排列；指针靠近视口上下边缘时持续滚动；保存期间只禁用排序，失败保留已加载顺序，409 自动重载并提示。

## 约定

## 外部集成

- **GitHub Actions / ghcr.io**：push 到 `master` 或 `v*` 标签时运行测试、构建并推送镜像；PR 构建镜像但不推送。仓库需允许 Packages 写入（公开仓库默认允许 Actions 使用 `GITHUB_TOKEN` 推送）。
- **VPS 反向代理**：由现有反向代理提供 HTTPS 与域名；应用只监听 `127.0.0.1:8080`；反代须保留 Host，并在覆盖 `X-Forwarded-For` 时设置 `TRUST_PROXY=true`。
- **备份**：SQLite 卷备份或管理员 JSON 导出；不提供导入。
- 无数据库、缓存、对象存储等外部服务。

## 已知限制

- 单管理员、单 SQLite 写连接；不支持并发多用户或水平扩展。
- 无评分历史、审计日志、JSON 导入、暗色主题、国际化。
- 评分与模型删除为硬删除；模型与维度归档可恢复，永久删除会级联评分（模型还级联文字记录）。
- 模型隐藏使匿名模型列表与详情直链不可达；管理员仍可从设置、工作台与登录态详情访问。
- 模型评语只保留当前值，无历史版本、富文本或按语言分栏；评语日期由管理员手填，不由系统自动更新。
- 权重 0 的数值维度仍出现在排行、详情与对比中，只是不计分；全部启用维度都不纳入时，排行显示独立空态，工作台保留数值表但综合分为空。
- 文字维度不进入排行、对比与工作台；把文字维度改为数值维度后，历史文字记录仍保留在导出中但不在界面展示。
- 维护模式期间会话过期后 API 返回 503，需要刷新页面才能回到维护页；不追加客户端自动刷新。
- 浏览器验收为手工执行，无端到端自动化；Go/前端纯函数与 HTTP 集成测试覆盖主要规则。
- 真实触屏手势需人工验收；自动化仅验证合成 `pointerType=touch` 的生命周期与清理。
- 百分比模式是站点级显示偏好，由管理员在设置页切换：`/api/rankings` 与 `/api/export` 仍返回绝对分值，匿名访客读取同一设置；其他已打开页面刷新后生效，不做实时推送。若要求对外不披露原始分，需服务端过滤，属另一轮范围。
- 本机无 Docker，镜像与 Compose 的实际启动需在 CI/VPS 验证。

## 术语

- **维度**：可增减的评分项，评分为不小于 0 的有限数，不设上限。
- **权重**：全局唯一的维度系数，0–100；不另设评分方案层。
- **覆盖率**：当前权重中已评分维度权重占全部启用权重的比例。
- **相对强度**：百分比模式下得分在榜单区间中的位置，最高分 100%、最低分 1%；无有效区间显示破折号。
- **暂定**：覆盖率低于 80% 的排名标记。
- **不纳入评分**：权重为 0 的维度，数值仍展示与录入，但不进入综合分、覆盖率、名次与排序。
- **隐藏**：模型退出公开排行、对比候选、名次编号、匿名模型列表与匿名详情；管理员仍可在工作台、设置与登录态详情访问。
- **模型评语**：模型档案中的独立公开文本，带公开开关与手填日期；公开后显示在详情页底部，未公开时仅管理员可见。
- **文字维度**：以一段自由文本代替数值评分的维度，权重固定为 0，只在详情页展示、评分弹窗录入，不参与任何计算。
- **归档**：模型或维度从列表、展示与计算中移除但保留数据，可恢复；与永久删除不同。
