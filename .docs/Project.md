## 概述

- **定位**：LLM Rank，一个用于个人记录、评分与比较 LLM 表现的自托管 Web 服务。
- **阶段**：首版实现完成，当前处于维护与小步演进。代码、测试、部署配置与 CI 已落地；生产镜像由 GitHub Actions 构建。
- **范围**：单管理员维护模型、维度、全局维度权重与评分；公开只读排行；加权综合分与覆盖率；模型详情、对比、评分工作台；JSON 导出；Docker Compose 与 GHCR 镜像。
- **非目标**：多用户/注册/OAuth、评论社区、自动抓取 benchmark、AI 自动评分、原生 App、实时协作、国际化、付费、暗色主题、评分历史、JSON 导入。

## 环境与运行

- **平台**：Linux x86_64（WSL 文件系统），开发与测试在本机；生产为个人 VPS。
- **运行时**：Go 1.27；Node 24 + pnpm 11.23；SQLite（`modernc.org/sqlite`，纯 Go，无 CGO）；React 19 + TypeScript 7 + Vite 8。
- **版本管理**：git；远端 [Evan-1777/llm-rankings](https://github.com/Evan-1777/llm-rankings)（公开）；`master` 为当前分支。
- **依赖**：Go 模块（`go.mod` / `go.sum`）；前端 pnpm（`web/pnpm-lock.yaml`），Markdown 渲染使用 `react-markdown` 10.1.0，不引入 GFM、代码高亮或 UI 组件库。生产镜像由 CI 构建，本机无 Docker。
- **本地运行**：
  1. `pnpm --dir web install`
  2. `pnpm --dir web build`（写入 `web/dist`，供 Go 内嵌）
  3. 设置必需环境变量后运行 `go run ./cmd/server`
  4. 开发前端时可运行 `pnpm --dir web dev`，Vite 将 `/api` 代理到 `127.0.0.1:8080`
- **环境变量**：
  - `PORT`：监听端口，默认 8080。
  - `DB_PATH`：SQLite 文件路径，默认 `./llm-rank.db`；生产为 `/data/llm-rank.db`。
  - `ADMIN_PASSWORD_HASH`：必填，bcrypt 哈希；缺失或格式错误时启动失败。
  - `SESSION_SECRET`：必填，至少 32 字节；用于 HMAC 签名 Cookie。
  - `COOKIE_SECURE`：默认 false；HTTPS 生产环境设为 true。
  - `TRUST_PROXY`：默认 false；仅当反向代理覆盖 `X-Forwarded-For` 时设为 true。
- **验证基线**：`go test ./...`、`go vet ./...`、`CGO_ENABLED=0 go build ./cmd/server`、`pnpm --dir web test`（Node 原生 `node --test`）、`pnpm --dir web typecheck`、`pnpm --dir web build`。
- **部署**：
  - CI 将镜像推送到 `ghcr.io/evan-1777/llm-rankings`（`latest` 与 `sha-*`、分支、版本标签）。
  - 复制 `deploy/.env.example` 为 `deploy/.env`，填写镜像、密码哈希与会话密钥。
  - `docker compose --env-file deploy/.env -f deploy/compose.yaml pull`，随后 `up -d`。
  - 容器只绑定 `127.0.0.1:8080`，由宿主反向代理终止 TLS；SQLite 使用命名卷 `llm-rank-data` 挂载到 `/data`。
- **运行约束**：
  - 本机未安装 Docker；不本地构建镜像，镜像构建由 GitHub Actions 验证。
  - 前端构建产物通过 `//go:embed all:dist` 进入 Go 二进制；生产只运行一个进程。
  - SQLite 使用 WAL、外键与单连接；备份以数据卷或 JSON 导出为准。

## API 与数据

### API

#### 认证与站点
- `GET /api/health`
- `GET /api/bootstrap`
- `POST /api/auth/login`、`POST /api/auth/logout`
- `GET /api/display-settings`（公共）；`PUT /api/display-settings`（管理员，需同时提交三个开关 `scorePercentageMode`、`scorePercentageMaxMode`、`maintenanceMode` 与必传字符串 `rankingNotes`；缺失或超 20,000 个 Unicode 码点返回字段级 422，正文不 trim）

#### 排行
- `GET /api/rankings`；`GET /api/rankings?includeHidden=1`（管理员，隐藏行保留分值与 `hidden: true`，名次为空）

#### 维度
- `GET /api/dimensions`；`POST /api/dimensions`；`PATCH /api/dimensions/{id}`；`PUT /api/dimensions/order`；`POST /api/dimensions/{id}/archive|restore`；`DELETE /api/dimensions/{id}`（维度载荷含 `textMode`）
- 重排接收含归档项的完整 ID 排列；载荷结构/重复/非正 ID 为 422，合法 ID 集合与当前库不一致为 409。

#### 模型
- `GET /api/models`（匿名不含隐藏模型；管理员列表含 `commentary`、`commentaryPublic`、`commentaryAt`）；`GET /api/models?includeArchived=1`（管理员）
- `POST /api/models`（创建不接收评语）；`GET /api/models/{slug}`（公开评语对所有人，未公开评语仅管理员；匿名访问隐藏模型或归档模型返回 404）
- `PATCH /api/models/{slug}`（支持部分字段，`hidden` 与评语三字段可单独提交）；`DELETE /api/models/{slug}`；`POST /api/models/{slug}/archive|restore`

#### 评分与文字
- `PUT /api/models/{slug}/scores/{dimensionId}`；`DELETE /api/models/{slug}/scores/{dimensionId}`（文字维度拒绝数值写入；删除幂等）
- `PUT /api/models/{slug}/texts/{dimensionId}`（管理员，载荷 `{text}`；空串清空并返回 204）

#### 导出
- `GET /api/export`（管理员，含归档与隐藏模型、维度 `textMode` 与 `texts` 数组、模型评语三字段）

### 数据模型

- `dimensions`：名称、描述、0–100 权重、`text_mode` 0/1、展示位置 `position`、归档时间。
- `models`：唯一 slug、名称、厂商、私人备注、`hidden` 0/1、`archived_at`、`commentary`、`commentary_public` 0/1、`commentary_at`。
- `scores`：模型 + 维度复合主键、非负 REAL、备注、更新时间。
- `dimension_texts`：模型 + 文字维度复合主键、内容、更新时间。
- `display_settings`：单例 `id = 1`、`score_percentage_mode` 0/1、`score_percentage_max_mode` 0/1、`maintenance_mode` 0/1、`ranking_notes`（默认空串的 Markdown 正文）。
- 表间外键级联；不插入种子数据；展示位置按原 ID 初始化，新建追加末尾。

### 评分与排名

- 只计权重 > 0 的启用数值维度；权重 0 维度仍出现在排行、详情与对比的展示快照中，但不进入综合分、覆盖率与排序。
- 综合分按已评分维度的权重归一，不设上限，按两位小数展示；单维度评分保留一位小数。
- 覆盖率 = 已评分权重 / 总权重，显示向下截断到一位小数，低于 80% 标记「暂定」。
- 同分按覆盖率高者、名称（小写码点序）、slug 排序；未评分与隐藏模型始终置底，隐藏模型不占名次，可见模型名次连续；官方排名不随视图排序改变。
- 求和按维度 ID 稳定顺序而非 map 顺序，避免浮点累加顺序造成末位漂移。
- 详情页逐维度计算名次，只计该维度已评分模型；按分值、名称与 slug 次序编号；未评分显示破折号，不改变官方综合排名。
- 公开排行、对比候选与 bootstrap 计数排除隐藏模型；管理员 `includeHidden=1` 可读取隐藏行。

### 模型可见性与生命周期

- **隐藏**：模型退出公开排行、对比候选、名次编号、匿名模型列表与匿名详情；管理员工作台、设置与登录态详情保留。
- **归档**：模型或维度退出全部列表、详情与写入，可恢复；永久删除才级联评分（模型还级联文字记录）。
- **模型完整度**：模型行分子与分母只计启用且权重 > 0 的维度；全部已存评分单独作为总数展示，归档评分不被吞掉。
- **评语与备注**：评语是独立公开文本，带公开开关与手填日期；私人备注仅管理员可见，两者互不覆盖。

### 认证与安全

- bcrypt 哈希存环境变量；HMAC 签名 `llmrank_session` HttpOnly Cookie，24 小时；`COOKIE_SECURE` 控制 Secure。
- 登录失败每 IP 15 分钟 5 次；写请求在带 `Origin` 时校验其 host 与 `Host` 一致，缺失 `Origin` 放行以兼容同源 SPA。
- 安全响应头含 CSP、`X-Frame-Options`、`X-Content-Type-Options`、`Referrer-Policy`；所有 `/api` 响应带 `Cache-Control: no-store`，静态资源缓存策略不变。
- 公开接口不返回私人备注；隐藏模型不进入匿名模型列表，匿名详情直链返回 404。
- 维护模式开启时，除健康检查、登录、登出与公开显示设置外，匿名 `/api` 请求统一返回 503 `maintenance`；管理员 Cookie 不受影响。门禁先判断登录态，再读取站点设置，已认证请求不触发 `display_settings` 查询。

### 静态资源

- `assets/` 下带哈希文件使用一年 immutable 缓存；其他文件一天；缺失的 `assets/` 与带扩展名路径返回 404，其余路径回落到 `index.html`；API 未知路径返回 JSON 404。

## 前端

### 路由与入口

- 路由：`/`（排行）、`/models/:slug`（详情）、`/compare?models=...`（对比）、`/workbench`（工作台）、`/settings?tab=dimensions|models|data|display`（设置）、`/login`（登录）。
- 页头、排行空态与维护页不渲染登录链接或按钮，`/login` 仅通过直接 URL 访问；未登录访问受保护页由 `RequireAdmin` 重定向到 `/login?next=...`。
- 维护模式开启时，未登录访客访问任意非登录路径只渲染维护页；维护页不渲染页头与导航。

### 页面结构

- **排行**：表头即排序控件；评分通过共享评分弹窗或工作台快捷编辑；模型只通过共享模型表单创建；顶部统计展示维度、权重、模型、已评分与更新时间。站点备注在榜单主体与表脚之后、对比浮条之前以 14px/1.75 弱色正文展示，空内容不渲染区域，加载或请求失败不拿备注充当反馈。
- **详情**：同时展示综合排名与逐维度名次；文字维度在数值表下方独立阅读，其后依次为模型评语与管理员私人备注；隐藏模型无对比入口与下一步导航。
- **对比**：最多 4 个模型，移动端改为纵向卡片；候选从当前排行派生。
- **工作台**：语义表格，维度分值常驻并可按表头排序；默认覆盖率升序暴露补测优先级；隐藏模型浅灰置于可见行之后。
- **设置**：独立于排行，分区为维度、模型、数据、显示；模型分区拆分启用与归档并常驻底部归档区；维度支持拖动或方向键排序。显示分区末尾提供带标签的 Markdown 备注文本框与显式保存按钮，草稿不自动发布；未保存离开拦截站内路径跳转与刷新，内部 tab 切换不拦截。
- **状态**：每页具备加载骨架、错误重试、空状态与成功反馈；站点设置尚未返回时先显示加载占位；无数据时给出下一步入口；空态只依据本页已加载数据，bootstrap 计数仅作加载前占位。

### 显示口径

| 开关 | 作用域 | 默认 | 行为 |
|---|---|---|---|
| 百分比模式 | 站点级 `display_settings` | 关闭 | 综合分与维度分改为百分比，排行、详情、对比与移动对比卡片共享，所有访客生效 |
| 最高分占比 | 站点级 `display_settings` | 关闭 | 仅在百分比模式开启时可切换；关闭时按分差口径，开启时按得分 ÷ 同项最高分 |
| 维度得分强调 | 当前浏览器 `localStorage` | 开启 | 只读维度得分按全榜同维度 min/max 显示红蓝色阶 |
| 维护模式 | 站点级 `display_settings` | 关闭 | 未登录访客只显示维护页 |

- 分差口径：`strength = 1 + 99 × (value − min) / (max − min)`，最高分 100%、最低分 1%；零区间与未评分显示破折号。
- 最高分占比：`value / max × 100`，最高分 100%、零分 0%；最高分为 0 或缺失显示破折号；全同分时最大值为真实最高分，显示 100%。
- 详情相对条与数字同口径：实际分值模式与最高分占比模式按最高分归一；分差百分比模式按相对强度填充；全同分与未评分保持零宽。
- 三个站点开关一次提交完整值，保存失败同时回滚；百分比关闭时最高分占比开关禁用但保留已存值，避免切换父开关时丢失偏好。
- 评分工作台与评分弹窗始终显示实际分值，不随显示模式改变；排序、名次、覆盖率、色阶与导出不受百分比模式影响。

### 评分与快捷编辑

- **评分弹窗**：打开后优先聚焦首个数值输入，无数值维度时聚焦首个文本框；未保存改动拦截站内跳转与 `beforeunload`；关闭后焦点回到触发按钮。
- 评分预览实时更新综合分与排名；预览前按 slug 合并当前模型，不依赖公开排行是否包含它；隐藏模型预览置底且不编号。
- 评分输入拒绝负数、NaN、Infinity，允许 12.5 与更大有限值；文字维度多行输入上限 2000 字符，与数值评分串行保存，空文字清空记录；备注只能附属于已评分维度，上限 500 字符。
- 保存失败保留弹窗与草稿，页脚显示原因；部分写入时说明已提交数量；评分删除可重复调用以便重试。
- **工作台快捷编辑**：开关文案固定为“快捷编辑”，以 `aria-pressed` 表示状态；编辑态把维度单元格换成同尺寸无边框输入，不新增行、不重复标签、不改变行高。
- 综合分、名次、覆盖率与行顺序冻结；显式表头排序只重排视图并按 slug 保留草稿；保存按模型 slug + 维度 id 串行提交，空值删除、未变化不请求、省略备注保留原备注。
- 每成功一项推进基线；部分失败显示已保存/剩余数量；取消只放弃剩余未提交项；保存成功后重载并按当前排序重排；保存中禁用输入、底部操作与模式开关。
- 保存态离开确认说明已发出请求会完成、剩余项不再提交；组件卸载后不再提示或回写；未保存时拦截站内跳转、刷新与退出，退出或保存后焦点回到开关。

### 模型与维度管理

- **模型**：设置页按名称列出启用模型，行内依次提供查看、编辑、隐藏/显示、归档与永久删除；隐藏模型显示「已隐藏」标签并保留在设置列表；归档模型只出现在列表下方「已归档」区。
- 编辑弹窗仅编辑态提供模型评语、评语时间与公开开关，私人备注保持最后；创建弹窗不出现评语字段；slug 创建后不可修改。
- **厂商**：仍为自由文本；表单接收父页已加载的模型列表，按 trim、去空、精确去重后以中文 locale 排序；原生 select 提供“不填写”、已有厂商与“新厂商…”，候选来自父页快照，不额外请求。
- **维度**：新建时默认权重 50；取消「不纳入评分」时若当前权重非正整数则回退 50；文字维度必须权重 0；维度归档保留分数与权重，可恢复。
- **维度排序**：序号区为拖动手柄；拖动或方向键调整顺序，释放后一次性提交含归档项的完整 ID 排列；指针靠近视口上下边缘时持续滚动；保存期间只禁用排序，失败保留已加载顺序，409 自动重载并提示。

### 视觉与可访问性

- 瑞士/编辑式排版，纸白 `#F2EFE6`、墨黑 `#14130F`、信号红 `#B92A20`；0 圆角、无阴影/渐变、1px 分隔线；桌面 12 栏，内容最大 1500px。
- 移动端表格隐藏维度列（排行、详情与对比；工作台仅表格容器横向滚动），保留排名、模型、综合分、覆盖率与操作；页面级不横向溢出。
- 隐藏模型在工作台的模型名、厂商、维度值、综合分、名次、覆盖率数字与进度条统一使用 `--ink-3`（约 4.97:1），覆盖率「暂定」标记保留信号红。
- 功能文字不小于 10px，移动主按钮 44px，行内图标 34px；维度拖动手柄桌面 52×44px、≤900px 44×48px，对应首列 60/44px；详情维度表右对齐等宽数字名次列，移动端保留名次并隐藏相对条。
- 维度色阶低分端暖红 `#e89a8b`（下划线 `#8f1c14`），高分端冷蓝 `#9fcbd2`（下划线 `#174f5b`），中点回到纸白；强度取 `0.18 + 0.82 × 距中点比例`，以百分比写入 `color-mix()`。
- 色阶端点文字对比度 8.34:1（红）与 10.57:1（蓝）；2px 下划线跟随分值文字宽度；排行与详情在强调开启时显示“低分红 → 高分蓝”图例；`forced-colors` 与打印移除底色与下划线。
- 交互与可访问性沿用 Apple HIG：清晰层级、克制反馈、键盘操作与焦点恢复；设置页 Tab 使用 roving tabindex 与左右方向键，维度手柄在读屏名称与 `aria-keyshortcuts` 中说明上下方向键。

## 约定

- **语言**：用户可见文本中文；代码标识符、注释、日志英文。
- **Go**：标准库优先；`net/http` + `ServeMux` 方法路由；`log/slog`；错误向上返回，HTTP 层映射为 `{error:{code,message,fields?}}`。
- **前端**：函数组件 + hooks；CSS Modules + CSS 自定义属性；不引入 UI 组件库与图表库；图标使用内联 SVG；不加载外部字体。
- **数据**：迁移只追加、不改已执行文件；迁移只建表，不插入任何种子数据；评分写入统一四舍五入到一位小数。
- **API**：`/api` 前缀；JSON；写请求要求 `Content-Type: application/json`；Cookie `HttpOnly`、`SameSite=Lax`；公开读接口不返回私人备注。
- **Git**：Conventional Commits 英文类型 + 中文描述；不提交 `.env`、密钥、数据库文件或构建产物。

## 关键约束与取舍

### 运行与数据

- 单管理员 + 公开只读；不引入用户表、注册或 OAuth。
- 单二进制部署：Go + SQLite + 预构建前端；不引入常驻 Node、外部数据库或缓存。
- 迁移追加、零种子；首次使用由管理员创建维度、模型与评分。
- 排名实时计算不落库；官方排名不随视图排序改变。

### 评分与排名

- 单一全局权重直接属于维度，0–100 整数；不设评分方案或方案切换层。
- 权重 0 是「不纳入评分」的唯一来源；数值仍展示与录入，但不进入综合分、覆盖率、名次与排序；文字维度权重固定 0。
- 评分只要求有限且不小于 0，不设上限；综合分可超过 10；先归一权重再乘分数，避免有限极大值溢出。
- 同分比较统一为小写码点序，前端预览与 Go 计算共用同一契约。
- 详情维度名次只计该维度已评分模型，不新增接口。

### 生命周期与内容

- 隐藏与归档分离：隐藏只影响公开可见性，归档退出全部列表、详情与写入；永久删除才级联。
- 文字维度独立存储于 `dimension_texts`，不复用 `scores.note`；只进详情与评分弹窗，不进入排行、对比与工作台；改为数值维度后历史文字保留在导出中但不在界面展示。
- 评语独立于私人备注；评语日期手填，只存 `YYYY-MM-DD` 文本，不做时区换算；正文为空时不渲染区块。
- 厂商复用不建实体：候选由父页快照派生，仍为自由文本；不提供厂商管理、别名合并或批量重命名。

### 显示、交互与安全

- 显示偏好默认本地，站点百分比、最高分占比、维护模式存 `display_settings`；维度强调只存当前浏览器，退出登录不清除。
- 色阶只做展示：按全榜实际得分 min/max 取色，不按已选子集重算，不按百分比数值重算；同分或无区间保持无底色。
- 快捷编辑按差分串行保存，不新增批量接口；省略备注的评分 PUT 保留原备注；评分删除幂等。
- 登录入口只保留直接 URL；不新增页面级路径判断、登录开关或后端认证改动。
- 维护模式复用 `display_settings` 单例，门禁放在 API 中间件；不新增服务端 HTML 模板。
- 排行榜备注复用同一单例与完整 PUT，不新增资源或路由；服务端按 Unicode 码点限制 20,000 字符以约束公开配置载荷，前端不设 `maxLength`，超限错误回填文本框。
- Markdown 仅 CommonMark 文本结构，由 `react-markdown` 渲染；跳过原始 HTML 与图片，沿用解析器默认安全 URL 处理，不引入 GFM、代码高亮或额外清洗插件。读取失败时设置页禁止以默认值覆盖服务器内容，重试使用独立状态且不卸载页面。
- 安全控制按单管理员威胁模型：bcrypt 环境变量、HMAC Cookie、登录限流、Origin 校验、CSP 与 API no-store；不引入用户体系或额外密钥管理。
- 前端不引入组件库、图表库与外部字体；以 CSS Modules 和设计令牌维持视觉一致性。

- **GitHub Actions / ghcr.io**：push 到 `master` 或 `v*` 标签时运行测试、构建并推送镜像；PR 构建镜像但不推送。仓库需允许 Packages 写入。

## 已知限制

- 单管理员、单 SQLite 写连接；不支持并发多用户或水平扩展。
- 无评分历史、审计日志、JSON 导入、暗色主题、国际化。
- 评分与模型删除为硬删除；模型与维度归档可恢复，永久删除会级联评分（模型还级联文字记录）。
- 模型隐藏使匿名模型列表与详情直链不可达；管理员仍可从设置、工作台与登录态详情访问。
- 模型评语只保留当前值，无历史版本、富文本或按语言分栏；评语日期由管理员手填，不由系统自动更新。
- 权重 0 的数值维度仍出现在排行、详情与对比中，只是不计分；全部启用维度都不纳入时，排行显示独立空态，工作台保留数值表但综合分为空。
- 文字维度不进入排行、对比与工作台；把文字维度改为数值维度后，历史文字记录仍保留在导出中但不在界面展示。
- 维护模式期间会话过期后 API 返回 503，需要刷新页面才能回到维护页；不追加客户端自动刷新。
- 浏览器验收为手工执行，无端到端自动化；Go/前端纯函数与 HTTP 集成测试覆盖主要规则；真实触屏手势需人工验收。
- 显示模式为站点级偏好，其他已打开页面刷新后生效，不做实时推送；`/api/rankings` 与 `/api/export` 仍返回绝对分值，若要求对外不披露原始分需服务端过滤，属另一轮范围。
- 排行榜备注为纯文本 Markdown：不支持图片、GFM 表格/任务列表、数学公式与原始 HTML；超长错误只在设置页显示，不提供字符计数器。
- JSON 导出不含显示设置与排行榜备注，完整备份以数据卷为准。
- 色阶仍按实际得分 min/max 定位；全同分维度没有有效区间，保持无底色。
- 排名按请求全量载入并计算，详情页客户端与服务端各计算一次；个人规模可接受，模型或评分增长后需缓存或合并请求。
- 本机无 Docker，镜像与 Compose 的实际启动需在 CI/VPS 验证。

## 术语

- **维度**：可增减的评分项，评分为不小于 0 的有限数，不设上限。
- **权重**：全局唯一的维度系数，0–100；不另设评分方案层。
- **覆盖率**：当前权重中已评分维度权重占全部启用权重的比例。
- **相对强度**：百分比模式默认口径下得分在榜单区间中的位置，最高分 100%、最低分 1%；无有效区间显示破折号。
- **最高分占比**：百分比模式的可选口径，分值为得分 ÷ 同项最高分，最高分 100%、零分 0%；最高分为 0 或缺失显示破折号。
- **暂定**：覆盖率低于 80% 的排名标记。
- **不纳入评分**：权重为 0 的维度，数值仍展示与录入，但不进入综合分、覆盖率、名次与排序。
- **隐藏**：模型退出公开排行、对比候选、名次编号、匿名模型列表与匿名详情；管理员仍可在工作台、设置与登录态详情访问。
- **模型评语**：模型档案中的独立公开文本，带公开开关与手填日期；公开后显示在详情页底部，未公开时仅管理员可见。
- **文字维度**：以一段自由文本代替数值评分的维度，权重固定为 0，只在详情页展示、评分弹窗录入，不参与任何计算。
- **归档**：模型或维度从列表、展示与计算中移除但保留数据，可恢复；与永久删除不同。
- **排行榜备注**：站点级、公开只读的 Markdown 正文，由管理员在显示设置中显式保存；空内容不渲染。
