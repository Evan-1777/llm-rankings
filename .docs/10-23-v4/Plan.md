## 1. 背景与目标

`Project.md` 已增至 48 KB，混有当前事实、当前/上一增量、53 条编年决策与逐轮测试日志。随着每次小改动继续追加，Agent 建立上下文的成本持续上升，且历史记录与当前事实容易产生两种表述。

目标：把它重构为“当前事实与不变量”的单一参考，历史过程交给 `.docs/` 归档。

## 2. 结构决定

- 删除“当前增量/上一增量”，概述只保留定位、阶段、范围、非目标。
- API 按认证、排行、维度、模型、评分、导出分组；前端按路由、页面、显示、评分、管理、视觉分组。
- 53 条编年决策收口为按主题组织的“关键约束与取舍”，只保留仍约束未来设计的部分。
- 逐轮测试日志移出，保留验证基线、最近结论与归档指针。
- 不嵌入 HTML 图表：该文件是 Agent 上下文，优先可检索、低 token 与稳定渲染。

## 3. 结果

- 文件从约 48 KB 降至约 27 KB，主章节稳定为 12 个。
- 维护表指向新章节；新增“历史变更不写入本文件”的边界。
